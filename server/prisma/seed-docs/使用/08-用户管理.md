# 用户管理使用教程

用户管理仅管理员可见。在左侧点击 **用户管理**，进入 **账号与权限** 页面。

当前是自助注册模式：用户用手机号接收短信验证码并登录，首次登录会自动创建账号，**不需要管理员审批**。这个页面用于管理已有账号的角色、功能模块权限和密码。

## 查看和筛选账号

页面上方可以按手机号、用户名、姓名或部门搜索，也可以按角色筛选。

表格会显示手机号、角色、部门、创建时间和权限范围。新用户登录后就会出现在这里，不需要先“通过审批”。

## 修改角色

点击用户行右侧的 **编辑**，可以选择：

- **管理员：** 拥有全部功能模块权限，可以进入用户管理、提示词管理和数据看板。
- **普通用户：** 只看到默认开放模块和管理员授予的模块。

管理员权限很高，只给真正负责系统运维、账号管理和提示词维护的人。

## 配置功能模块权限

给普通用户勾选需要开放的功能模块，保存后该用户刷新页面或下次登录时生效。

管理员拥有全部权限，不需要逐项勾选。用户管理和提示词管理属于管理员专属能力，不能单独授予普通用户。

## 重置密码

在编辑弹窗的 **重置密码** 输入框中填写新密码，留空表示不修改。密码至少 8 位。

用户设置密码后，可以在登录页选择 **密码登录**，使用手机号和密码登录；密码登录仍需要图形验证码。没有设置密码的用户继续使用短信验证码登录。

重置后请通过安全渠道把临时密码告诉用户，并要求尽快自行修改，不要把明文密码长期保存在聊天记录或文档里。

## 删除账号

点击用户行右侧的 **删除** 并确认后，账号及其工作区数据会被删除，操作不可撤销。

系统不允许删除当前登录的管理员自己，避免误删最后一个管理入口。删除前先确认该账号不再需要保留，并提醒用户导出需要留存的内容。

## 注意事项

- 手机号和用户名在编辑弹窗中不可修改；填错时让用户用正确手机号重新登录。
- 用户注册即激活，不需要再走审批流程。
- 管理员账号数量要控制，不要把日常账号都设为管理员。
- 离职、外包结束或临时账号到期后及时删除或收回权限。
