常见问题

你可能想问

会编造业绩和人员吗？

不会。参考材料中没有的具体值，会保留要点并写成符合招标要求的笼统口径（如"按招标要求配备相应人员"），不编造人名与证书。

字数能精确控制吗？

目录阶段按预算规划小节数，正文阶段单节目标自动摊分，生成后全文复核：轻微超出自动精简，明显超出保留内容并明确提示。

数据安全吗？

招标文件与生成结果仅存于你的专属项目工作区；基于开源底座，支持私有化部署评估。

支持哪些文件格式？

解析支持 doc / docx / wps / pdf / xls / xlsx / md / txt；导出支持 Word（.docx）与 PDF。

多人同时用会卡吗？

平台内置多 Key 池与按用户公平调度，团队同时生成时每人都能获得稳定的生成份额。
